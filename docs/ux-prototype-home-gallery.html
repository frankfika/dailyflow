DailyFlow · 主页原型 5 版本对比

同一份任务，做了五种"chill"的方式

从左到右、从上到下，越往下越像"翻开一页纸"，越不像"打开一个 app"。每张图都可以点开看实际效果（链接在卡片底部）。

v3.2 chill 版 基础
方向：App 套纸面，给原设计加纸面背景 + 手写体 + 留白 + 一条切换按钮。
特点：整体还是"一个 app"，只是被暖米色 + washi tape 装饰过。
标准 手写
打开 v3.2.html →
v3.3 chill+ 三档 装饰
方向：默认就 chill，加上纸夹 / 涂鸦 / 微旋转 / 不对称 checkbox。
特点：三档切换（标准 / 手写 / 极简），是 5 版里装饰最多的一版。
标准 手写 极简
打开 v3.3.html →
v3.4 笔记本版 纸感
方向：删掉侧栏，做成横线笔记本页 + 装订红线。
特点：580px 宽、单列、有横线纸背景、pill 改成手写体彩色文本，开始不像 app。
标准 手写
打开 v3.4.html →
v3.5 极简版 减法
方向：把所有 UI 砍光：没工具栏 / AI 条 / section header / 进度条 / 胶囊。
特点：只剩"日期 + intention + 任务列表 + 小结"，540px 宽，行高 1.9。
标准 手写
打开 v3.5.html →
v3.6 写给自己的一封信 散文
方向：根本不是清单了——是今天早上写给自己的一封信。开篇"你好，今天"，落款"明天的你"。
特点：没有 checkbox、没有 section header、没有 pill。任务只是散文里提到的几件事，靠手写小字注脚标紧急程度。
标准 手写
打开 v3.6.html →
怎么挑：想最像 app、但要 chill → v3.2 / v3.3。想像个有质感的工具 → v3.4。想像翻一页笔记本 → v3.5。想像读一封信 → v3.6。
