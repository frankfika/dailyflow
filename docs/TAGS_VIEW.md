# Tags 视图功能说明

## 功能概述

Tags 视图提供了一个全新的维度来组织和查看你的笔记和任务。通过标签聚合，你可以快速找到所有相关的内容，无论它们分散在哪个日期或项目中。

## 核心特性

### 1. 标签聚合展示

- **自动收集**: 自动从所有笔记和任务中提取标签
- **统计信息**: 显示每个标签下的笔记数量和任务数量
- **排序**: 按总数量降序排列，最常用的标签排在前面

### 2. 卡片式布局

每个标签显示为一个独立的卡片，包含：
- 标签名称（带 # 前缀）
- 总项目数
- 笔记数量（蓝色图标）
- 任务数量（绿色图标）

### 3. 展开查看详情

点击标签卡片可以展开查看：
- **笔记列表**: 显示该标签下的所有笔记
  - 笔记标题
  - 创建日期
- **任务列表**: 显示该标签下的所有任务
  - 任务标题
  - 完成状态（勾选框）
  - 来源日期

### 4. 搜索功能

- 顶部搜索框支持实时过滤标签
- 输入关键词即可快速定位相关标签
- 支持清除搜索

### 5. 上下文过滤

- 自动跟随 Work/Life 上下文切换
- 只显示当前上下文下的标签和内容
- 系统标签（work、life、delayed 等）自动过滤

## 使用场景

### 场景 1: 项目管理

```
标签: #产品设计
- 3 个笔记（设计文档、用户反馈、竞品分析）
- 5 个任务（原型设计、用户测试、迭代优化等）
```

### 场景 2: 知识管理

```
标签: #学习
- 8 个笔记（读书笔记、课程笔记、心得体会）
- 2 个任务（完成作业、复习重点）
```

### 场景 3: 主题追踪

```
标签: #客户A
- 5 个笔记（会议记录、需求文档、沟通记录）
- 3 个任务（需求确认、方案设计、交付验收）
```

## 技术实现

### 数据收集

```typescript
// ���所有笔记中提取标签
allNotes.forEach(note => {
  note.tags.forEach(tag => {
    if (!systemTags.includes(tag)) {
      tagMap.get(tag).notes.push(note);
    }
  });
});

// 从所有任务中提取标签
allTasks.forEach(task => {
  (task.tags || []).forEach(tag => {
    if (!systemTags.includes(tag)) {
      tagMap.get(tag).tasks.push(task);
    }
  });
});
```

### 上下文过滤

```typescript
// Work 上下文: 显示 work 标签的内容 + 没有 work/life 标签的内容
if (activeContext === 'work') {
  if (hasWorkTag || (!hasWorkTag && !hasLifeTag)) {
    // 包含此项
  }
}

// Life 上下文: 只显示 life 标签的内容
if (activeContext === 'life') {
  if (hasLifeTag) {
    // 包含此项
  }
}
```

### 排序逻辑

```typescript
// 按总数量降序排列
.sort((a, b) => b.totalCount - a.totalCount)
```

## 与其他视图的关系

### Today 视图
- 显示今天的任务和笔记
- 按类别（category）组织

### Projects 视图
- 显示所有待办任务
- 按项目/类别分组
- 支持搜索和筛选

### Notes 视图
- 显示所有笔记
- 支持类型、人员、时间等多维度筛选

### Tags 视图（新增）
- 显示所有笔记和任务
- 按标签分组
- 提供标签维度的聚合视图

## 使用建议

### 1. 标签命名规范

建议使用清晰、一致的标签命名���
- 项目标签: `#项目名`
- 客户标签: `#客户名`
- 主题标签: `#主题`
- 技能标签: `#技能`

### 2. 标签层次

可以使用标签的组合来表达层次关系：
- `#产品` + `#设计` = 产品设计相关
- `#产品` + `#开发` = 产品开发相关

### 3. 定期整理

- 定期查看 Tags 视图
- 合并相似的标签
- 删除不再使用的标签

## 快捷操作

- **切换视图**: 点击侧边栏的"标签"
- **搜索标签**: 在搜索框输入关键词
- **展开详情**: 点击标签卡片
- **收起详情**: 再次点击标签卡片
