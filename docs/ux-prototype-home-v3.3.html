v3.3 · chill+ 三档可调

① 三档切换（右上角）：标准（chill 默认）→ 手写（中文 + 拉丁全手写 + 装饰全开）→ 极简（手写 + 弱化 pill 与辅助元素，更"空白"）。
② 默认就 chill：暖米纸面 + 三条彩色 washi tape（amber / sage / dusk）+ 纸夹 + 微弱咖啡渍——不再"切了才 chill"。
③ 手绘细节满载：checkbox 用不对称圆角矩形（手画感），事件卡片有 0.15° 微旋转（贴便签感），5 处 SVG 涂鸦（星花 / 箭头 / 虚线圆 / 双波浪 / 点点）。
④ 手写体覆盖更广：手写模式下任务标题、按钮、输入框占位符都进手写体——整页像"手帐笔记"而不是"App 局部换字体"。
⑤ 留白再上调：body 间距 22→24，事件卡片 padding 14→16，行高 1.65→1.7——呼吸感再+1。
⑥ 颗粒感纸面：背景三层 radial-gradient 颗粒，app 内部两层颗粒——比 v3.2 多了 2 倍纹理，但仍然"远看干净、近看有质感"。
