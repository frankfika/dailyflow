## 功能入口

### 1. 自动检测（启动时）

应用启动后 3 秒，如果检测到新版本，会在顶部显示蓝色横幅：

```
┌─────────────────────────────────────────────────────────┐
│  📥  发现新版本                                          │
│      v0.3.0 → v0.4.0                                    │
│                                    [下载]  [×]          │
└─────────────────────────────────────────────────────────┘
```

**特点**:
- 蓝色背景，醒目但不打扰
- 显示版本号对比
- 一键跳转下载
- 可手动关闭

## 用户体验流程

### 场景 1: 有新版本可用

1. **启动应用**
   - 用户打开 DailyFlow
   - 3 秒后自动检查更新

2. **发现更新**
   - 顶部显示蓝色横幅
   - "发现新版本 v0.3.0 → v0.4.0"

3. **下载更新**
   - 点击"下载"按钮
   - 跳转到 GitHub Releases 页面
   - 根据平台自动推荐安装包

4. **安装更新**
   - 下载对应平台的安装包
   - 关闭应用
   - 安装新版本
   - 重新启动

### 场景 2: 已是最新版本

1. **手动检查**
   - 打开设置 → 通用
   - 点击"检查更新"

2. **显示结果**
   - 绿色提示框
   - "✅ 已是最新版本"
   - 显示当前版本号

3. **继续使用**
   - 关闭设置
   - 继续正常使用

### 场景 3: 网络问题

1. **检查失败**
   - 无法连接 GitHub API
   - 静默失败，不显示错误

2. **不影响使用**
   - 应用正常运行
   - 用户可以稍后重试

## 技术细节

### 版本检测逻辑

```typescript
// 1. 获取最新版本
const release = await fetch('https://api.github.com/repos/frankfika/dailyflow/releases/latest');
const latestVersion = release.tag_name.replace(/^v/, '');

// 2. 比较版本号
const hasUpdate = compareVersions(latestVersion, currentVersion) > 0;

// 3. 选择安装包
const platform = getPlatform(); // 'macos' | 'windows' | 'linux'
const asset = release.assets.find(a => {
  if (platform === 'macos') return a.name.endsWith('.dmg');
  if (platform === 'windows') return a.name.endsWith('.msi');
  if (platform === 'linux') return a.name.endsWith('.AppImage');
});
```

### 平台识别

| 平台 | 检测方式 | 推荐格式 |
|------|---------|---------|
| macOS | `navigator.userAgent` 包含 'mac' | `.dmg` 或 `.app.tar.gz` |
| Windows | `navigator.userAgent` 包含 'win' | `.msi` 或 `.exe` |
| Linux | `navigator.userAgent` 包含 'linux' | `.AppImage` 或 `.deb` |

### 版本号比较

```typescript
compareVersions('0.4.0', '0.3.0') // 返回 1 (v1 > v2)
compareVersions('0.3.0', '0.3.0') // 返回 0 (相等)
compareVersions('0.2.0', '0.3.0') // 返回 -1 (v1 < v2)
```

## 常见问题

### Q: 为什么检查失败？
A: 可能原因:
- 网络无法访问 GitHub API
- GitHub API 频率限制（60次/小时）
- 仓库不存在或没有 Releases

### Q: 如何测试功能？
A: 方法:
1. 修改 `CURRENT_VERSION` 为较低版本（如 '0.1.0'）
2. 重启应用
3. 应该会显示更新提示

### Q: 支持自动安装吗？
A: 当前版本不支持，需要手动下载安装。未来可能添加此功能。

### Q: 会收集用户数据吗？
A: 不会。仅检查版本号，不发送任何用户信息。
