## 0. 设计总纲

### 0.1 页面模型：两页 + 浮层（修正 v2 的"永远在主页"矛盾）

| 层级 | 内容 | 进入方式 |
|---|---|---|
| **主页**（第 1 页） | Today：日期 + 主动建议 + 焦点 + **按事件/脑图分组的任务** + 添加 | 启动 / `⌘T` |
| **深度页**（第 2 页，唯一例外） | Events 画布（**即脑图**，见 §0.4） | 点事件组头 / `⌘2` / 任务"转成项目" / `⌘K` |
| **浮层** | 笔记 / AI / 日历 / 记忆 / 设置 | `⌘3-7` / `⌘,` / `⌘K` / 图标栏 |

原则（修正 v2 原则 3）：**主页是永久的家；Events 是唯一第二页（画布需要沉浸空间）；其余一切是浮层，esc 即回主页。**

### 0.2 导航：保留 60px 图标栏（修正"砍到 0"）

不把导航砍没——新手需要可见入口（修正 P0-4）：

```
┌────┬────┬────┬────┬────┐
│ ⌘K │ 今 │ 事 │ 笔 │ AI │   ← 60px 图标栏：今日 / 事件 / 笔记 / AI + ⌘K
└────┴────┴────┴────┴────┘
```

- 图标栏**常驻**（桌面展开可到 230px 显示文字，收起 60px 纯图标）
- 日历 / 记忆 / 团队 / 设置 → `⌘K`（低频 / 管理类）
- 首次启动 onboarding 教 3 个键：`⌘K` / `⌘N` / `回车`

### 0.3 五条核心原则（修正版）

1. **不展示功能，展示路径** —— 用户感受到的是"我在做事"，不是"我选功能"。
2. **能力按需浮现** —— 不点不开、不展开不见；需要时伸手就有，不需要时隐形。
3. **两页 + 浮层** —— 主页为家，Events 为深度页，其余浮层，esc 永远回主页。
4. **键盘 > 鼠标，按钮兜底** —— 高频动作有快捷键；新手靠图标栏也能发现主要功能。
5. **复杂操作在画布** —— 事件/脑图/AI 推进用独立全屏空间。

### 0.4 关键修正：事件 = 脑图，Today 按事件分组（v3.1 核心）

**代码事实**（已核实）：

- 每个 Event 绑定一个 `mindmapId`，Events 的画布（`EventCanvas`）**本身就是脑图**（节点 `kind`、拖拽、树布局）。
- 存在**孤儿组件** `MindMapView`（独立脑图：7 种节点 / AI 整理 3 策略 / 模板 / 撤销重做 50 步 / 画布内搜索）——**有完整功能 + 测试，但没有任何页面渲染它**。只有 Events 画布在真正跑，且 Events 目前**没有** AI 整理（只有 AI 推进）。
- 用户感知的"脑图" = Events 画布。脑图能力被劈成两半（一半孤儿、一半在 Events）——这是"脑图很重要但总觉得不对劲"的根源。

**定稿决策**：

1. **消灭孤儿**：把 `MindMapView` 的能力（AI 整理 3 策略、模板、7 节点、撤销重做）**并入 Events 画布**，保留一个实现。代码层面"脑图" = "事件画布"，用户层面"事件" = "脑图"。
2. **Today 按事件/脑图分组**：主页任务按来源事件（脑图）分组显示——组头 = 事件名，点组头进全屏画布；独立任务单独一组。脑图成为主页的**组织结构**，而非图标栏里的第二个页面。**这是"功能融入"而非"降级"**。
3. **双向桥接**：画布节点"排进今天" → 任务出现在主页对应事件分组；主页任务"来自 ↗"chip → 点跳画布高亮节点。
4. **Today ↔ Events 状态不丢**：进画布记住来源上下文，esc / `⌘T` 回来主页原样。
