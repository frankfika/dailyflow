v3.2 核心变化 · chill 化重排

① 暖米色纸面 + 胶带装饰：把"#F3F5F3 灰白"换成"#EFE7D7 暖米"，配四角胶带，整页像一张贴在自己桌上的便签纸，更放松。
② 手写体可切换（右上角 · 标准 / 手写）：手写模式用 Caveat 渲染日期、事件名、焦点标题、独立任务分组，副标题还保留衬线英文以保证可读性——chill 但不"难读"。
③ 留白大幅增加：外壳 padding 24→48，body 间距 12→22，行高 1.5→1.65，圆角统一 18~22——"呼吸感"是 chill 的核心。
④ 手绘涂鸦装饰（手写模式可见）：4 处 SVG 涂鸦——小波浪、星花、弯箭头——给关键信息加点"手写笔记"的温度。
⑤ 类型层级更柔和：主标题用衬线 / 手写体，正文用 Inter，标签用 paper2 底色 + dashed 边线——更接近"手帐笔记"而不是"App 列表"。
⑥ 焦点状态升级：focus 区从"一行小条"变成"独立卡片"——焦点是今天的灵魂，不应该被压扁。
