# DailyFlow UX 极简 Wireframe（v0.5 · 用户路径优先）

> ## 我之前 v0.1-v0.4 全部搞错了
>
> 你说的"功能很好的融入"是：用户感受到的是一个页面在帮 ta 做今天的事，**根本不会意识到"原来这里还有个 AI Chat / Memory / Settings"**。
>
> 我之前所有版本都是在做"功能分门别类"——把 44 个能力拆到"主页 / 浮层 / 砍"。这是产品经理的思路，**不是用户的思路**。
>
> 这版重写。我不再列功能清单（你比我清楚），我只画 4 张图：
> 1. **打开应用看到什么**（默认态）
> 2. **做一件具体的事时，能力怎么浮现**（添加任务 + 完成任务 + 想做深度思考 + 想用 AI 帮忙）
> 3. **想"管理"时怎么办**（⌘K 召唤，平时不显示）
> 4. **键盘全图谱**（高手用户的肌肉记忆）
>
> 参考：[Things 3 极简设计](https://blakecrosley.com/guides/design/things) · [Linear ⌘K](https://137foundry.com/articles/command-palette-interface-users-actually-reach-for) · [Notion `/` 召唤](https://sspai.com/post/95397) · [Reflect 主页](https://reflect.app/blog/reflect-open) · [Progressive Disclosure 原则](https://www.uxtigers.com/post/progressive-disclosure)

## 2. 做事路径 · 用户做具体一件事时，能力如何自然浮现

### 2.1 添加任务（最常见 · 90% 时间在做的事）

#### a) 简单加 → 直接打字回车

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ + 完成 DSH 接入测试                                       [📅] [+tag]    ➤   │
└──────────────────────────────────────────────────────────────────────────────┘
   ↳ 打字 → 回车 → 加进去 → 输入框清空 → 继续打字（焦点不丢）
   ↳ **2 秒搞定一件事**。用户感受：极简。
```

#### b) 想加截止日期 → 点 `📅`

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ + 准备周五站会                            [📅 本周五 ▾]            [+tag] ➤   │
└──────────────────────────────────────────────────────────────────────────────┘
                 ↓ 点 📅 出现
        ┌──────────────────┐
        │ 📅 今天           │
        │ 📅 明天           │
        │ 📅 本周五         │
        │ 📅 下周一         │
        │ ────────────     │
        │ 📅 自定义…       │
        └──────────────────┘
   ↳ 选一个 → 输入框变成 "准备周五站会 [📅 本周五 ▾]" → 回车
   ↳ **3 步搞定**。用户感受：自然。
```

#### c) 想加 tag → 点 `+tag`

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ + 优化 onboarding 文案                                       [📅] [+tag] ➤   │
└──────────────────────────────────────────────────────────────────────────────┘
                          ↓ 点 +tag 出现
        ┌──────────────────────────────┐
        │ # work   # life   # academy   │
        │ # cshub  # okrreview         │
        │ ─────────────────────────── │
        │ 输入新 tag…   [Enter]         │
        └──────────────────────────────┘
```

#### d) 想加更多（重复 / AI 脑暴 / 关联笔记 / 转项目）→ 点 `⋯`

```
        ┌──────────────────────────────┐
        │ 🔁 每天/每周/每月重复         │
        │ 🤖 AI 脑暴（一段话 → 多任务）│
        │ 📌 关联到笔记                │
        │ 📋 转成项目                  │
        │ 🎙 启动会议转写              │
        └──────────────────────────────┘
```

**关键：用户不点 `⋯`，这些功能永远不出现。**

#### e) 想一次加多条 → 连输

```
+ 处理保密协议 [📅 今天] ➤
+ 准备周五站会 [📅 本周五] ➤
+ 优化 onboarding ➤
   ↳ 每条加完，输入框清空但焦点保留 → 一直打字一直回车
```

### 2.2 完成任务 · 7 个高级动作以行内方式浮现

用户在某个任务上**点一下（不是勾选）**：

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  ☐  完成 DSH 接入测试                                          今天截止 · 🔥 │
│                                                                            ▾ │  ← 点这里展开行内动作
└──────────────────────────────────────────────────────────────────────────────┘
                            ↓ 点开后
┌──────────────────────────────────────────────────────────────────────────────┐
│  ☐  完成 DSH 接入测试                                          今天截止 · 🔥 │
│                                                                            ▴ │
│  ┌────────────────────────────────────────────────────────────────────────┐  │
│  │ 📅 改日期    🏷 加 tag    🔁 重复    ⏱ 番茄钟    ✏ 详细描述         │  │  ← 行内动作条
│  ├────────────────────────────────────────────────────────────────────────┤  │
│  │ 关联：来源 ↗ 事件「DSH 接入项目」   ·  关联笔记：2 篇                │  │  ← 数据关联浮现
│  │ 最近评论：（点 + 加评论）                                              │  │
│  ├────────────────────────────────────────────────────────────────────────┤  │
│  │ 🤖 AI 帮我：拆解成子任务 / 改写更清晰 / 转成事件 / 总结                │  │  ← AI 能力浮现
│  │                                                [删除]  [已完成 ✓]     │  │
│  └────────────────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────────────┘
```

**7 个"高级功能"全部以行内动作浮现：**

| 能力 | 浮现方式 | 不展开时在哪 |
|---|---|---|
| 改日期 | 行内按钮 📅 | 数据字段 deadline |
| 加 tag | 行内按钮 🏷 | 数据字段 tags |
| 重复 | 行内按钮 🔁 | 数据字段 recurrence |
| 番茄钟 | 行内按钮 ⏱ | 新功能 |
| 详细描述 | 行内按钮 ✏ | 数据字段 description |
| **关联事件（Mind Map 节点）** | 行内 chip `来源 ↗` | 数据字段 originMindmapId |
| 关联笔记 | 行内计数 + chip | 数据字段 linkedNoteIds |
| **AI 拆解 / 改写 / 转事件** | 行内 AI 区 | 永远在这里但不点不出 |
| 完成评论 | 完成后弹小 prompt | 数据字段 comments |

**用户视角：勾个任务而已。想操作什么点什么。**

## 3. ⌘K 召唤 · 所有"管理"动作的家

### 3.1 设计原则

- 不再有侧边栏、不再有 tab。
- ⌘K 平时不显示，按一下才出。
- 用户通过 ⌘K 完成所有"切"和"管理"。
- esc 回主页。

### 3.2 ⌘K 能做的一切

| 类型 | 例子 |
|---|---|
| **跳** | 跳到今天 / 跳到事件画布 / 跳到某日期 / 跳到某笔记 / 跳到某任务 |
| **搜** | 搜任务 / 搜笔记 / 搜事件 / 搜记忆（3 层命中） |
| **操作** | 快速收集 / 今日复盘 / 整理遗留 / 切上下文 / 切工作区 |
| **设置** | 进设置（⌘, 直达） |
| **AI** | `?` 前缀进 AI 问答（也可在主页底部直接问） |

### 3.3 进设置 → 浮层（不切走）

## 4. 键盘图谱（高手用户）

```
全局
────────────────────────────────────────────
  ⌘K              万能命令面板（搜索 / 命令 / 跳）
  ⌘T              跳到今天
  ⌘N              添加任务（光标进底部输入框）
  ⌘B              AI 脑暴（光标进底部输入框 + 切到 AI 模式）
  ⌘,              设置
  ⌘⇧1             切换 Work / Life
  ⌘⇧W             切换工作区
  Esc              关闭任何浮层 / 收起展开行 / 回主页
  ⌘D              历史日期选择

主页
────────────────────────────────────────────
  任务点击        展开行内动作（7 个能力浮现）
  ⌘↩              在底部输入框直接提交当前内容
  Tab（在底部）    切换输入模式（任务 / 笔记 / 脑暴 / AI 问答）

任务行内
────────────────────────────────────────────
  E               编辑标题
  D               改日期
  T               改 tag
  R               改重复
  N               加详细描述
  ⌘⏎              标记完成（弹评论 prompt）
  Backspace       删除（带二次确认）
  → / ←           展开 / 收起

事件画布（Events）
────────────────────────────────────────────
  Tab             加子节点
```

## 5. 做事路径总图（用户视角）

```
打开应用
   ↓
[主页：今天 + 清单 + 输入框]
   │
   ├── 加任务 ──→ 输入框打字 ──→ 回车
   │                ├── 要日期？点 📅
   │                ├── 要 tag？点 +tag
   │                └── 更多？点 ⋯
   │
   ├── 看任务 ──→ 点任务行 ──→ 展开行内动作
   │                ├── 改日期 / tag / 重复
   │                ├── 关联笔记 / 事件
   │                ├── AI 拆解 / 改写 / 转事件
   │                └── 完成（弹评论 prompt）
   │
   ├── 想深度思考 ──→ 点 "转成事件" ──→ 进 Events 画布
   │                                       ├── 双 pane 拖拽编辑
   │                                       ├── AI 整理 3 策略
   │                                       └── AI 推进（Harness）
   │
   ├── 想 AI 帮忙 ──→ 底部 `?` 或 ⌘K `?` ──→ 内嵌问答条
   │                或 AI 脑暴 / 任务行 AI 区
   │
   ├── 想搜/想切 ──→ ⌘K ──→ 搜索/命令/最近
   │
   └── 想管理 ──→ ⌘, ──→ 设置浮层
```

**没有"AI Chat 页"、"Memory 页"、"Settings 页"这种**——它们都是动作，不是地方。
