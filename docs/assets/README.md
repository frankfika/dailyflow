# Assets

This directory stores DailyFlow visual assets.

- `logo.svg`: local product logo for documentation.
- `home.png`, `notes.png`, `ai-chat.png`, and `settings.png` are captured from the running local application by `scripts/capture-screenshots.mjs`.
- Do not add mocked screenshots. Refresh the real assets after UI changes with `node scripts/capture-screenshots.mjs`.
