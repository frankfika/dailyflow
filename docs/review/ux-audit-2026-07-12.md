# DailyFlow UX 审计 (2026-07-12)

> v1.0.3, 纯观察无建议. 引用 `file:line`.

## 1. 用户旅程卡点 (4 角色)

- **新用户** 装好进 `WorkspaceSetup` (`src/components/WorkspaceSetup.tsx:117-211`), 点「开始」直接 `window.location.reload()` (`App.tsx:1012`), 落到空白 Today 页, 没有任何 first-run 引导: 不知道 `Cmd+N` 加任务 (快捷键在 `App.tsx:610`, 只有 FAB tooltip 提到 `App.tsx:1695`), 不知道 Work/Life 切在 sidebar 底部 (`Sidebar.tsx:227-256`).
- **重度日复一日** 切 work/life 看 tasks vs notes, 两边规则已统一 (`src/utils/contextFilter.ts:26-39` ✓), 但每条新任务自动打 `work`/`life` tag (`TaskInputPanel.tsx:334-336`), **无 UI 提示这是 system tag, 改 context 应走 sidebar 而非手改 tag**; 标签输入自由 (`TaskInputPanel.tsx:204-211`), 输错 `#worklife` 不纠错.
- **AI 重度** Brain Dump 在 `TaskInputPanel.tsx:139-172` 弹层, 提交后只产 task 不存 note (文本 state `App.tsx:179` 提交即清空), **回头找不到原文**; AI Chat 想"今天 tasks + 一个 note"上下文, `ContextPicker` (`AIChat.tsx:32`) 支持, 但 `TaskCard` 全文无 "send to AI" prop (`TaskCard.tsx` grep 0 命中).
- **会议/笔记用户** 在 today 空白处想建 meeting_note, `DailyNoteCards.tsx:65-78` 虚线占位只产 `type: note`; 必须先 `setActiveTab('notes')` (`App.tsx:1617` prop 已在, DailyNoteCards 没传) → 点 "新建" (`Notes.tsx:298-304`) → NoteEditor dropdown 改类型 (`NoteEditor.tsx:667-677`); 一周后 search `Notes.tsx:312-318` 搜 "张三" 命中 `mentions` (`:236-238` ✓), 搜 "Q3" 命中 body, **meeting 的 `time`/`endTime` 字段不在搜索范围** (`:227-244` 搜的字段没有这两个).

声明的 IA (`docs/PRODUCT.md:91-118`) 是 5 段 (今日/项目/思维导图/资料库/设置), 运行时 (`App.tsx:145`, `Sidebar.tsx:202-221`) 只有 3 tab (today/notes/ai-chat):

- 「Projects」顶级 tab 缺, `src/components/Projects.tsx` 422 行实现完整, **全文件 0 外部 import** (`grep "import.*Projects" src/` 0 命中).
- 「Thinking Workspace」后端全套 (`server/routes/thinkingWorkspaces.ts`, `src/api/client.ts:316-358`) + 测试齐, **前端 0 入口** (sidebar / tabs / command 全无).
- UX_REDESIGN §4 计划的 4 tab (Today/Timeline/Projects/Notes) 实际 Timeline 降级为 sidebar 内日期列表 (`Sidebar.tsx:103-199`), Projects / Thinking Workspace 都不在侧栏.
- `showQuickNoteEditor` state (`App.tsx:139`) + NoteEditor 弹层 (`App.tsx:1784-1848`) 按 §4 应删, 仍活着; 6 个 `setShowQuickNoteEditor(true)` 调用点 (`App.tsx:1422, 1461, 1509, 1541, 1618, 1619`), 暴露入口只剩 `DailyNoteCards.tsx:52-61` 的 "笔记" 按钮.
- `App.tsx:1310-1335` 用首个非系统 tag 当 cat 标题渲染, **完全不读 `activeContext`**, work/life 视图下展示相同 cat 列表.
- Work/Life tag 写死 (`TaskInputPanel.tsx:334, 648-650`, `aiToolExecutor.ts:49-51`), 删 tag 时 work 视图会瞬间把 task 推给 life, 无中间态.

## 3. AI 入口碎片化

3 个 AI 入口跑同一套逻辑, 互不共享状态:

- **`AIChat` tab** (`App.tsx:1623-1652`, 1387 行) + **`FloatingAIPanel` 浮窗** (`App.tsx:1148-1188`, 1179 行) **共享 ~90% 代码**: `getFriendlyErrorMessage` (`AIChat.tsx:37-79` vs `FloatingAIPanel.tsx:38-80`) 一字不差, `buildContextText` (`:302-349` vs `:333-380`) 同构, `handleSend` / session 状态机 (line 96-272) 完全复制, ReactMarkdown + 5 个 lucide import 重复; **两个 session 列表互相不可见** (都写 `localStorage['df_ai_chat_store']`, `src/types/chat.ts:49, 68`).
- AI Summary 在 `Notes.tsx:439-551` 状态独立, **不调 `getFriendlyErrorMessage`** (`:190-195` `console.error` + `setSummaryError(err.message)` 裸错误); 数据源只读 `notes` (`:148-176` `filteredNotes = notes`), 看不到 daily tasks (UX_REDESIGN §5.2 "数据源 Daily+Notes 都读" 未做).
- 8 处 `aiApi.summarize` (Notes.tsx:181, NoteEditor.tsx:172/231/292, AIChat.tsx:439, FloatingAIPanel.tsx:518, AIWorkflow.tsx:115, App.tsx:633) **每处都手填 `apiKey/model/baseUrl`**, 即使已走后端代理 (`src/api/client.ts:760-772` + `server/routes/ai.ts:60-110`).
- AI Chat session 全在 `localStorage` (`types/chat.ts:62-69`), **浏览器清数据 = 历史全丢**, 无导入/导出.
- `@mention` 解析 (`NoteCard.tsx:33-51`) 用 `@[\w一-龥-]+`, **不支持连字符/点** (e.g. `@jean-luc.picard` 不命中).
