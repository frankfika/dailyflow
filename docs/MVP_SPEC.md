# DailyFlow MVP 规格

> 目标：用最小成本验证 DailyFlow 的核心价值——自动迁移未完成任务，并保持 Obsidian/Markdown 工作流不被破坏。

---

## 1. MVP 目标

MVP 只解决三件事：

1. 能读取现有 Markdown 日记目录。
2. 能展示、编辑、完成当天任务。
3. 能把未完成任务可靠迁移到下一天。

长期项目、思维导图、附件管理先设计数据接口和入口，但不在第一版做复杂实现。

## 2. 用户故事

| 编号 | 用户故事 | 优先级 | 验收标准 |
|---|---|---:|---|
| US-01 | 作为用户，我可以配置 Obsidian 日记目录 | P0 | 输入目录后系统能识别日期文件 |
| US-02 | 作为用户，我可以查看今天的任务 | P0 | 页面按标题/分类展示 `- [ ]` 和 `- [x]` |
| US-03 | 作为用户，我可以勾选任务完成 | P0 | Markdown 中对应 checkbox 被更新为 `- [x]` |
| US-04 | 作为用户，我可以生成今天或明天的日记 | P0 | 文件不存在时按模板创建 |
| US-05 | 作为用户，我希望未完成任务自动迁移 | P0 | 子任务、说明、附件、标签完整保留 |
| US-06 | 作为用户，我可以搜索任务 | P0 | SQLite 索引支持按标题、标签、日期检索 |
| US-07 | 作为用户，我可以看到任务来自哪一天 | P1 | 迁移任务显示 source date |
| US-08 | 作为用户，我可以把任务关联到项目 | P1 | `#project:name` 被解析并在项目列表展示 |
| US-09 | 作为用户，我可以手动 commit 当前更改 | P1 | Git 状态面板显示更改并可提交 |

## 3. MVP 页面

### 3.1 首次设置

- 选择日记目录。
- 设置文件命名规则：`YYYY-MM-DD.md` 或自定义路径模板。
- 设置自动迁移来源：昨天 / 最近一个有日记的日期。
- 设置迁移时间：打开应用时 / 每天固定时间 / 手动。

### 3.2 今日视图

- 顶部：日期切换、生成今日、迁移任务、同步状态。
- 主体：按 Markdown 标题聚合任务。
- 任务项：checkbox、标题、标签、deadline、project、展开详情。
- 底部：已完成任务折叠区。

### 3.3 Markdown 预览/编辑

- 左侧结构化任务视图。
- 右侧原始 Markdown 或预览。
- 编辑任务时只写回对应任务块，避免重排整个文件。

### 3.4 设置页

- 日记目录。
- 路径模板。
- 迁移规则。
- Git 仓库状态。
- SQLite 索引重建。

## 4. 迁移流程

```text
用户打开 DailyFlow
        ↓
检查今天文件是否存在
        ↓
不存在 → 创建今日模板
        ↓
找到迁移来源日期
        ↓
解析未完成任务块
        ↓
过滤 #no-rollover / future scheduled
        ↓
写入今日文件的待办区
        ↓
给来源任务追加 migrated 标记
        ↓
更新 SQLite 索引
        ↓
可选 Git commit
```

## 5. 验收标准

### 功能验收

- 能解析含中文标题、emoji、Obsidian wikilink 的 Markdown。
- 能保留嵌套子任务和 blockquote 说明。
- 同一个任务不会在同一天重复迁移。
- 勾选完成后刷新页面状态仍正确。
- 手动修改 Markdown 后可重建索引。

### 数据安全验收

- 写入前自动创建 `.bak` 或通过 Git 暂存原文件状态。
- 解析失败时不写入任何文件。
- Git 冲突文件不自动覆盖。
- 所有路径限制在用户配置的数据目录内。

### 体验验收

- 首次配置 3 分钟内完成。
- 今日任务页面 1 秒内打开。
- 普通迁移任务 3 秒内完成。
- 迁移结果可预览、可撤销。

## 6. 不做事项

- 不做多人协作。
- 不做移动端原生 App。
- 不做复杂 AI 自动排期。
- 不做完整日历邀请协议。
- 不做云账户系统。

## 7. 原型里程碑

| 里程碑 | 内容 | 预计时间 |
|---|---|---:|
| M0 | CLI 原型：解析和迁移 Markdown | 3-5 天 |
| M1 | Web 原型：今日视图和完成任务 | 1 周 |
| M2 | 设置页、索引、搜索、迁移预览 | 1 周 |
| M3 | Git commit、Docker、本地部署文档 | 3-5 天 |
