# LinkedIn Post - 中文

---

我做了一个本地优先的每日任务管理工具，解决了一个困扰我很久的问题：每天早上手动把昨天的未完成任务复制到新页面。

**DailyFlow** 的核心特点：

✅ 自动任务迁移 — 昨天没做完的，今天自动出现，标注来源日期
✅ Markdown 文件为数据源 — 完全离线，Obsidian/VS Code 随便打开
✅ AI Brain Dump — 把零散想法倒进去，AI 自动整理成任务
✅ 工作/生活上下文切换 — 一键过滤
✅ Git + IPFS 备份 — 双重保险

所有数据存在本地 .md 文件中，没有云端锁定。

技术栈：React 19 + TypeScript + Tailwind CSS 4 + Tauri 2 (Rust) + Express.js

支持 macOS / Windows / Linux

# LinkedIn Post - English

---

I built a local-first daily task manager that solves a daily pain point: manually copying yesterday's unfinished tasks to today's page every morning.

**DailyFlow's** core highlights:

✅ Automatic task rollover — unfinished tasks from yesterday auto-appear today with source date tracking
✅ Markdown files as data source — fully offline, open with Obsidian/VS Code
✅ AI Brain Dump — dump scattered thoughts, AI organizes into tasks
✅ Work/Life context switching — one tap, filtered views
✅ Git + IPFS backup — dual insurance

All data stored as local .md files. No cloud lock-in.

Tech stack: React 19 + TypeScript + Tailwind CSS 4 + Tauri 2 (Rust) + Express.js

Supports macOS / Windows / Linux
