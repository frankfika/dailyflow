# Twitter/X Thread

---

**1/ 🚀 我做了一个本地优先的每日任务管理工具，彻底告别每天早上手动整理未完成事项的痛苦**

用 Markdown 文件当数据源，自动帮你迁移跨日任务，Git/IPFS 备份，完全离线可用。

GitHub: https://github.com/frankfika/dailyflow

---

**2/ 核心功能：**

✅ 自动任务迁移 (Rollover) - 昨天没做完的，今天自动出现在你的清单里
✅ AI Brain Dump - 把零散想法倒进去，AI 自动提取任务、设截止日期
✅ 工作/生活上下文切换 - 一键过滤，互不干扰
✅ 笔记系统 - 普通笔记、会议记录、AI 总结
✅ Git + IPFS 备份 - 双重保险

---

**3/ 为什么做这个？**

每天早上手动把昨天的未完成任务复制到新页面，太烦了。
而且大多数 todo app 数据锁在云端，用起来不踏实。

DailyFlow 用 Markdown 文件作为唯一数据源，你的数据完全属于你自己。

---

**4/ 技术栈：**

React 19 + TypeScript + Tailwind CSS 4
Tauri 2 (Rust) 桌面端
Express.js 后端
本地优先，离线可用

支持 macOS / Windows / Linux
