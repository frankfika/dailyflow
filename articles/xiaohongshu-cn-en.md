# 小红书帖子 - English

---

🔥 **Finally! I built a tool that eliminates the daily task migration pain**

You know that 15-minute morning ritual of copying yesterday's unfinished tasks to today's page? I did it for a year. Then I built DailyFlow.

**Local-first daily task manager.**

**The core problem it solves:**
Every morning, unfinished tasks auto-appear in today's view with source date tracking. No more manual copying.

**Markdown-native:**
All tasks are .md files stored locally. No cloud lock-in, no service shutdown risk. Open with Obsidian, Typora, or VS Code.

**100% offline:**
No internet required. Works on flights, trains, dead-zone cafes.

**Cool features:**
• AI Brain Dump — dump your scattered thoughts, AI organizes them into tasks
• Work/Life context switching — one tap, filtered views
• Git/IPFS backup — dual insurance, never lose data
