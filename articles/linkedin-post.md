I built a local-first daily task management app that automatically migrates unfinished tasks to today.

No more manually copying yesterday's tasks every morning.

All data stored as Markdown files — your data, your control. Works offline.

🔗 https://github.com/frankfika/dailyflow

**Key Features:**

• Automatic task rollover with source date tracking
• AI Brain Dump — dump scattered thoughts, AI extracts tasks with deadlines
• Work/Life context switching
• Notes system (regular, meeting, AI summaries)
• Git + IPFS backup options

Built with React 19, TypeScript, Tailwind CSS 4, and Tauri 2 (Rust).

Available on macOS, Windows, and Linux.

If you're tired of manually managing task migrations every day, give it a try.
