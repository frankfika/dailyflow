# DailyFlow 社媒发布文案

此文件夹包含 DailyFlow 项目在各社交媒体平台发布的文案，每个文件都包含中文和英文两个版本。

## 文件列表

| 文件 | 平台 | 风格 |
|------|------|------|
| `xiaohongshu-cn-en.md` | 小红书 | 口语化、emoji、生活化 |
| `twitter-thread-cn-en.md` | Twitter/X | 简洁、thread 格式 |
| `weibo-jike-cn-en.md` | 微博/即刻 | 中长文、口语化 |
| `linkedin-cn-en.md` | LinkedIn | 专业、简洁 |
| `zhihu-cn-en.md` | 知乎 | 结构化、详细 |
| `reddit-cn-en.md` | Reddit | 社区化、直接 |
| `producthunt-cn-en.md` | Product Hunt | 产品化、正式 |
| `wechat-official-cn-en.md` | 公众号 | 深度、故事化 |

## 截图文件

截图存放在 `docs/assets/` 目录，发布时引用路径为 `docs/assets/xxx.png`

可用截图：

- `home.png` - 每日任务主界面
- `notes.png` - 笔记系统
- `ai-prompts.png` - AI 提示词库
- `settings.png` - 设置页面
- `projects.png` - 项目概览
- `markdown-view.png` - Markdown 文件视图

## 使用说明

1. 复制对应平台的文案
2. 根据平台特性调整格式（如微博限制字数、Twitter 限制推文长度）
3. 插入截图（使用相对路径 `docs/assets/xxx.png`）
4. 发布时附上 GitHub 链接
