# Product Hunt 发布文案

---

**Tagline:**

DailyFlow - Local-first daily task manager that auto-migrates unfinished tasks. Markdown-powered, offline-ready.

**Description:**

DailyFlow 是一个本地优先的每日任务管理桌面应用，用 Markdown 文件作为唯一数据源，自动处理跨日任务迁移。

每天早上一键查看今日任务，不用再手动整理昨天的未完成事项。

**Features:**

✅ Automatic task rollover with source date tracking
✅ Markdown-native data storage — your data, your control
✅ AI Brain Dump — extract tasks from scattered thoughts
✅ Work/Life context switching
✅ Notes system with @mentions and AI summaries
✅ Git + IPFS backup options
✅ 100% offline capable

**Target Users:**

- Knowledge workers who manage daily tasks
- Obsidian/Notion users looking for local-first alternatives
- Anyone frustrated with manual task migration every morning

**Tech:**

React 19, TypeScript, Tailwind CSS 4, Tauri 2 (Rust), Express.js

Supports macOS, Windows, Linux.
