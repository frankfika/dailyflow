# Twitter/X Thread - English

---

**🚀 Built a local-first daily task manager. No more manually copying yesterday's unfinished tasks every morning.**

Markdown files as data source, auto task rollover, Git/IPFS backup, 100% offline.

github.com/frankfika/dailyflow

---

**Features:**

✅ Automatic task rollover — unfinished tasks from yesterday auto-appear today
✅ AI Brain Dump — dump scattered thoughts, AI organizes into tasks
✅ Work/Life context switching — one tap, filtered views
✅ Notes system (regular/meeting/AI summary)
✅ Git + IPFS backup — dual insurance

![Main Interface](docs/assets/home.png)

---

**Why I built this:**

Manually copying yesterday's tasks every morning is tedious.
Most Todo apps lock your data in the cloud.
DailyFlow uses Markdown files as the single source of truth. Your data, your control.

---

**Tech stack:**

React 19 + TypeScript + Tailwind CSS 4
Tauri 2 (Rust) desktop
Supports macOS / Windows / Linux
