# 我做了一个本地优先的每日任务管理工具，彻底告别「每天早上手动整理未完成事项」的痛苦

## 为什么做这个？

相信很多人和我一样，每天早上要花 10-15 分钟把昨天的未完成任务手动复制到新页面。

更烦的是，大多数 Todo App 数据存在云端，用起来不踏实——万一哪天服务停了，或者网络不好，根本没法用。

于是我做了 **DailyFlow**，一个本地优先的每日任务管理桌面应用。

## 核心特性

### 1. 自动任务迁移 (Rollover)

这是 DailyFlow 最重要的功能。

每天打开应用，未完成的任务会自动迁移到今天的清单里，并且标注来源日期。已迁移的任务不会重复出现。

你可以预览要迁移的任务，确认后再执行，完全可控。

### 2. Markdown 为数据源

所有任务和笔记都以 Markdown 文件存储。

这意味着：
- 你的数据完全属于你自己，没有云端锁定
- 完全离线可用，不需要网络
- 可以用 Obsidian、Typora、VS Code 等任何编辑器打开
- 天然兼容 Git，版本控制无忧

### 3. AI Brain Dump

把零散的想法、会议的碎片一股脑倒进去，AI 自动帮你：
- 提取任务
- 分类打标签
- 设置截止日期

支持 DeepSeek、OpenAI、Anthropic 等多种 AI 服务。内置连接测试，一键验证 API 配置。

### 4. 工作/生活上下文切换

一键切换「工作模式」和「生活模式」。

有时周末也想看看有没有遗漏的工作任务，有时工作日想暂时忘掉生活琐事。上下文切换让任务自动过滤，互不干扰。

### 5. 笔记系统

独立的笔记功能，支持三种类型：
- **普通笔记**：记录想法、灵感、备忘
- **会议记录**：参会人、时间段、录音、@提及人员
- **AI 总结**：选中内容 + 提示词，AI 生成结构化总结

### 6. Git + IPFS 双重备份

- **Git 同步**：一键提交到 GitHub，状态栏实时显示同步状态
- **IPFS 备份**：通过 Pinata 上传完整工作区快照，去中心化永久存储

## 技术栈

- 前端：React 19 + TypeScript + Tailwind CSS 4
- 桌面：Tauri 2 (Rust)
- 后端：Express.js
- 支持：macOS / Windows / Linux
