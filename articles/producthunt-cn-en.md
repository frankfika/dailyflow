# Product Hunt Launch - 中文

---

**标语：**
DailyFlow - 本地优先的每日任务管理工具，自动迁移未完成任务，Markdown驱动，完全离线

**描述：**

DailyFlow 是一个本地优先的每日任务管理桌面应用，用 Markdown 文件作为唯一数据源，自动处理跨日任务迁移。

每天早上一键查看今日任务，不用再手动整理昨天的未完成事项。

**功能亮点：**

✅ 自动任务迁移 — 昨天没做完的，今天自动出现，标注来源日期
✅ Markdown 文件存储 — 数据完全属于你，没有云端锁定
✅ AI Brain Dump — 零散想法自动变任务，支持 DeepSeek/OpenAI/Anthropic
✅ 工作/生活上下文切换 — 一键过滤，互不干扰
✅ 笔记系统 — 普通笔记、会议记录、@提及、AI 总结
✅ Git + IPFS 备份 — 双重保险

# Product Hunt Launch - English

---

**Tagline:**
DailyFlow - Local-first daily task manager with automatic rollover. Markdown-powered, 100% offline.

**Description:**

DailyFlow is a local-first daily task management desktop app that uses Markdown files as its single source of truth, automatically handling cross-day task migration.

One click to see today's tasks every morning. No more manually copying yesterday's unfinished items.

**Features:**

✅ Automatic task rollover — unfinished tasks from yesterday auto-appear today with source date tracking
✅ Markdown file storage — your data, your control. No cloud lock-in
✅ AI Brain Dump — scattered thoughts → organized tasks. Supports DeepSeek/OpenAI/Anthropic
✅ Work/Life context switching — one tap, filtered views
✅ Notes system — regular, meeting notes with @mentions, AI summaries
✅ Git + IPFS backup — dual insurance

- Anyone frustrated with manual task migration every morning

**Tech Stack:**
React 19, TypeScript, Tailwind CSS 4, Tauri 2 (Rust), Express.js

Supports macOS, Windows, Linux.
