# Skill: 内容工厂 — 主编排

> 这是整个工作流的"大脑"，它自己不做内容生产，只负责顺序和交接。

## 触发条件

当用户说"启动内容工厂"或提供一个内容主题关键词时触发。

## 输出目录规则

每次运行创建独立的输出子目录，避免多次运行互相覆盖：

```
output/
├── 2026-04-21_ai开咖啡店/
│   ├── topic.md
│   ├── article.md
│   ├── images/
│   └── final.html
├── 2026-04-22_独立开发者出海/
│   ├── topic.md
│   ├── article.md
│   ├── images/
│   └── final.html
```

命名规则：`output/{日期}_{主题关键词}/`（取主题前 10 个字，去掉特殊字符）

## 执行流程

按以下顺序依次执行，每一步完成后检查产物是否存在：

设当前输出目录为 `$OUT`（如 `output/2026-04-21_ai开咖啡店/`）

### Step 1: 创建输出目录
- 根据当前日期和用户主题，创建 `$OUT` 目录及 `$OUT/images/` 子目录

### Step 2: 选题分析
- 调用 `topic-research` Skill
- 检查 `$OUT/topic.md` 是否已生成
- 如果文件不存在或为空，报告错误并停止

### Step 3: 内容写作
- 调用 `content-writing` Skill
- 检查 `$OUT/article.md` 是否已生成
- 确认文章字数在 2000-4000 之间

### Step 4: 配图生成
- 调用 `image-generation` Skill
- 检查 `$OUT/images/` 目录下是否有新图片
- 确认 `$OUT/article.md` 中的 `[IMAGE: ...]` 标记已被替换为图片引用

### Step 5: 排版发布
- 调用 `formatting` Skill
- 检查 `$OUT/final.html` 是否已生成
- 用浏览器打开验证排版效果

## 错误处理

- 任一步骤失败 → 报告失败原因 → 保留已生成的中间文件
- 不要删除中间产物，方便调试和断点续跑
- 如果某一步已有产物（如 `$OUT/topic.md` 已存在），询问用户是否跳过该步骤

## 使用示例

```
用户: 启动内容工厂，主题：一个人如何用 AI 开咖啡店
```

系统将：
1. 创建 `output/2026-04-21_ai开咖啡店/`
2. 自动执行：选题分析 → 内容写作 → 配图生成 → 排版发布
3. 最终输出 `output/2026-04-21_ai开咖啡店/final.html`
