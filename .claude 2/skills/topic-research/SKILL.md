# Skill: 选题分析

> 负责将用户给出的关键词扩展为一个经过评估的选题方案。

## 触发条件

当用户提供了一个内容主题关键词时触发。

## 执行步骤

1. **关键词扩展**：围绕用户给出的关键词，扩展 5-8 个子话题方向
   - 入门教程 / 实战案例 / 对比分析
   - 最新趋势 / 常见问题 / 最佳实践

2. **热度评估**：对每个子话题从以下维度打分（1-10）
   - 搜索热度：该话题的搜索量和讨论度
   - 内容稀缺度：现有高质量内容的多少（越少分越高）
   - 受众匹配度：与目标读者的相关性
   - 写作可行性：能否在一篇文章内讲清楚

3. **选题确定**：选择综合评分最高的话题
   - 输出标题 + 读者画像 + 核心价值
   - 输出 3-5 段文章结构建议

## 输出

写入 `$OUT/topic.md`（`$OUT` 由主编排 Skill 创建的当前输出目录），格式如下：

```markdown
# 选题分析报告

## 最终选题
- 标题：[文章标题]
- 目标读者：[读者画像]
- 核心价值：[一句话说明这篇文章能给读者带来什么]

## 文章结构建议
1. [段落1方向和要点]
2. [段落2方向和要点]
3. [段落3方向和要点]
4. [段落4方向和要点]

## 备选话题评分表
| 话题 | 热度 | 稀缺度 | 匹配度 | 可行性 | 总分 |
|------|------|--------|--------|--------|------|
| ...  | ...  | ...    | ...    | ...    | ...  |
```

## 注意事项

- 输出格式必须严格遵循上述模板，因为下游 Skill 会解析这个文件
- 总分 = (热度 + 稀缺度 + 匹配度 + 可行性) / 4
- 至少评估 5 个备选话题
